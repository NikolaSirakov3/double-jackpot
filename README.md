# Two Jackpots Wild Wheel — local game

## Start

Double-click `start.command`, then open <http://localhost:8080> in a browser.
From Terminal, the equivalent is:

```sh
cd "/Users/nikolasirakov/Documents/Inkastle/ink-double-jackpot/Double Jackpot/game"
python3 -m http.server 8080
```

## Controls

- Spin: click/tap **SPIN**, press `Space` or `Enter`, or use gamepad A.
- Change bet: **BET − / BET +**, arrow keys, or gamepad left/right.
- Mute: `M`.
- Paytable/settings: the info and gear buttons.
- QA fixtures: press `Q`, or start with `?qa=1`; force a line win, wheel trigger,
  or the documented 4,150× maximum win.
- Deterministic run: add `?seed=12345` to the URL.
- Runtime overlay: add `?dev=1`.

All credits are fictional and stored only in this browser's local storage.
